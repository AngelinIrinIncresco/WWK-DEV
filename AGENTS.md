# Project Guidelines & Guardrails

## Strict Deployment Policy
- **DO NOT DEPLOY CODE TO ANY SALESFORCE ORG** without explicit, written confirmation from the user.
- Commands such as `sf project deploy start`, `sfdx force:source:deploy`, or automated deployments are strictly forbidden unless explicitly commanded by the user.
- All code development, testing, and Git tracking must remain strictly local until explicit deployment instructions are given.
